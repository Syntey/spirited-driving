# First launch screens

> **Status:** draft, being iterated. Last updated 2026-11-07.
>
> The design for [First launch](README.md): three intro pages, then location and the vignette, then the
> [Map](../map/design.md). Uses the [Theme](../../theme.md).

## Flow

| Step | Page        | Action                    | Skip |
|------|-------------|---------------------------|------|
| 1    | What it is  | Next                      | Yes  |
| 2    | The budget  | Next                      | Yes  |
| 3    | The hand-off | Next                     | Yes  |
| 4    | Location    | Continue, then the system prompt | No |
| 5    | Vignette    | Yes, I have one / No      | No   |

- **Skip** jumps to Location. Location and the vignette are never skipped.
- The intro pages swipe both ways. Location and Vignette are reached only by Next or Skip.
- After the system prompt, whatever the answer, the vignette page follows. Answering the vignette opens the map.
- Back (Android) goes to the previous page; on the first page it leaves the app.

## Layout

Every page has the same three layers:

- **Illustration**, full screen, behind everything: two light sports cars on a winding road, seen from above. A
  red roadster after the MX-5 leads, and a white coupe after the GR86 follows, both in the right lane; simplified,
  no badges or logos. A day version for the light theme and a dusk version, with headlights, tail lights and
  street lamps on, for the dark theme. Decorative, so screen readers skip it.
- **Skip**, top right, on the intro pages.
- **Panel** at the bottom, on glass over the illustration ([Theme](../../theme.md#where-glass-is-used)): the
  page's content at the top, and the page dots and actions at the bottom.

The panel has the same height on every page, set by the tallest page, so it doesn't jump while swiping. It grows
with larger text sizes; if it reaches the top of the screen, its text scrolls.

## Pages

| Page        | Title                                   | Body                                                                                       | Extra |
|-------------|-----------------------------------------|--------------------------------------------------------------------------------------------|-------|
| What it is  | Take the fun way                        | For people who enjoy driving: curvy country roads, hills and passes instead of the motorway. | "Czechia for now" label above the title; terms line below the button |
| The budget  | You set the extra time                  | Pick a destination and how much longer you'll spend, like +30 min. You get the most fun route that fits. | A row of budget chips, +30 min selected |
| The hand-off | Drive it in Apple Maps / Google Maps   | Your route opens in [Apple Maps / Google Maps] for turn-by-turn guidance. Afterwards, tell us how it was. | |
| Location    | Start where you are                     | The map and your routes start from your location. Keep Precise Location on (iOS) / Choose Precise (Android), so routes start on the right road. | |
| Vignette    | Do you have a Czech motorway vignette?  | Without one, routes avoid motorways that need it. You can change this in Settings.         | |

- **Czechia for now:** a small label with a pin, on `tertiaryContainer`, as the theme uses tertiary for hints.
- **Terms line:** "By continuing, you accept the Terms and Privacy Policy.", with both as links. It sits on the
  first page, so Skip passes it too.
- **Budget chips:** the same chips as in [Route planning](../route-planning/design.md#budget), not tappable. Screen
  readers hear "Budget chips, +30 min selected".
- **Location:** one button, Continue, which shows the system prompt. There's no "Not now": the prompt has its own
  way to decline.
- **Vignette:** two buttons with the same style (tonal), so neither answer looks preferred.
- **Page dots:** five, the current one a wider capsule in primary. Screen readers hear "Step 2 of 5".

## Illustration

Two versions are drawn; one is still to be picked (open question 1):

- **Slides along the road:** one panorama five screens wide. Each step pans it a full screen width, moving with the
  swipe, so the road leaves each page exactly where it enters the next. The cars move along the road, so the drive
  shows progress; they stay above the panel.
- **Static:** one view of the panorama, the hairpins, on every page; only the panel changes.

With Reduce Motion (iOS) or animations turned off (Android), the sliding version fades between steps instead.

The artwork is generated by [tools/first-launch-art](../../../tools/first-launch-art/README.md).
