# Saved routes

> **Status:** draft, MVP. Last updated 2026-11-05.

Routes the user wants to drive again or later, on any device.

## What the user can do

- Save a planned route.
- See saved routes in a list, by name.
- Drive a saved route any time.
- Rename or delete a saved route.

## Rules

- A saved route keeps the exact route; it isn't planned again.
- Saved routes sync across the user's devices.

## Needs and provides

- **Needs:** routes from [Route planning](route-planning.md); [Account](account.md) for sign-in.
- **Provides:** a route for [Drive](drive.md).
